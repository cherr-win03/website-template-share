# 디자인 규칙 (포스터 카드 목록)

흰 바탕, 절제, 항목마다 한 가지 테마색. 값의 원본은 `public/design/tokens.css` 하나다. 화면 CSS(`base`·`components`·`layouts`)는 거기 있는 `--ui-*` 값만 쓴다(시험이 확인한다). 이 문서를 바꾸면 `tests/front-static.test.mjs` 도 같이 본다.

## 파일 구성

| 파일 | 하는 일 |
|---|---|
| `public/design/tokens.css` | 색·글자·간격·모서리·그림자·테마색. 브랜드를 바꾸는 곳은 맨 위 |
| `public/design/base.css` | 리셋, 본문, 링크, 제목, `.ui-sr-only`, 건너뛰기 링크, 초점, reduced-motion, forced-colors, `[hidden]` 가드 |
| `public/design/components.css` | 머리말·꼬리말·단추·칩·상태 칩·입력·선택지·오류·안내·상태 한 요소 |
| `public/design/layouts.css` | 포스터 카드 목록 격자, 상세(전폭 띠·sticky 카드·모바일 고정 바), 좁은 한 열 화면 |
| `public/app/` | 바닐라 JS 모듈(빌드 없음). 사이트 이름·메뉴·꼬리말은 `site.js` 한 파일 |

다른 React·정적 사이트에 가져갈 때는 `public/design/` 폴더를 그대로 복사하고 각 HTML 에서 `tokens → base → components → layouts` 순으로 link 한다. 선택자는 `ui-` 클래스와 `data-accent`·`data-status` 속성만 쓴다(ID·문서 구조에 묶지 않음).

## 굳은 규칙 13개 (이 템플릿 기준)

1. 순흑 `#000` 금지. 잉크 `#14181C`, 보조 `#5A6570`.
2. 글자 크기는 6단계(13/15/17/22/32/48)와 큰 숫자뿐. 간격은 4~72 토큰, 모서리는 12/20/999 세 가지.
3. 새 색을 만들지 않는다. 토큰과 테마색만. (CSS 에 hex 가 나오면 시험이 실패한다.)
4. 명조 글꼴 없음. 본문은 Pretendard Variable, 일본어는 시스템 일본어 글꼴 스택.
5. 색만으로 알리지 않는다. 오류는 앞의 "!" + 글, 선택은 ✓ 와 테두리, 상태 칩은 글자가 항상 같이 있다.
6. 흰 바탕. 색 상자·색 테두리·장식 막대·이모지를 공개 화면에 쓰지 않는다. 테마색 면은 카드·상세 띠·정보 카드뿐.
7. 주 단추(채운 알약)는 한 화면에 하나. 나머지는 테두리 알약(`ui-btn--secondary`)이나 글자 단추.
8. `[hidden]` 은 `base.css` 의 전역 규칙 하나가 책임진다. 컴포넌트마다 가드를 따로 쓰지 않고, 숨길 때는 `hidden` 속성을 쓴다.
9. 대비 4.5:1(큰 글자·비텍스트 3:1). 보조 글자를 테마 100 면 위 작은 글자에 쓰지 않는다. `--ui-line` 을 눌리는 요소 테두리로 쓰지 않는다.
10. 누름 영역 44px 이상(단추 48). 칩·메뉴·링크도 44px.
11. 테마 면 위 작은 글자는 `--ui-accent-900`.
12. 동적 값은 `data-*` 속성 + CSS 로, 꼭 필요하면 `element.style.setProperty`(CSSOM)만. 인라인 `<script>`·`<style>`·`style=`·`on*=` 금지(CSP `'self'`).
13. 화면을 바꾸면 `DESIGN_DOC_TEMPLATE.md` 형식으로 `docs/design/` 에 기록하고 넓은 화면(1280)·휴대폰(390) × ko·ja·en 캡처를 본다. 서버 동작·요청 본문은 디자인 변경에서 불변.

## 접근성 규칙

- **건너뛰기 링크** `.ui-skip` → `main#content[tabindex=-1]`. 해시 라우팅과 부딪치므로 `main.js` 가 클릭을 가로채 main 에 초점만 준다.
- **초점**: `:focus-visible` 3px `--ui-focus` + 간격. 카드 전체 링크는 `::after` 덮개에 링을 그린다. 프로그램이 옮긴 초점(제목·상태 칸)은 링을 그리지 않는다.
- **움직임 줄이기**: `prefers-reduced-motion` 에서 전역으로 애니메이션·전환을 끈다.
- **고대비(forced-colors)**: 칩 선택(3px 테두리), 상태 칩(테두리), 현재 메뉴, 오류·안내 표시, 불러오는 막대(`Highlight`)를 따로 처리한다.
- **읽기 규칙**: 눈으로만 보는 값(D-3)은 `aria-hidden` 으로 두고 읽을 문장(마감까지 3일 남음)은 `.ui-sr-only`. 포스터 이미지의 `alt` 는 비운다(제목이 옆에 있다). 새 탭 링크는 "(새 탭에서 열림)" 을 `.ui-sr-only` 로.
- **상태**: 불러오는 중·빈·오류는 한 요소(`.ui-state[data-state]`)가 `role=status|alert` 로 알린다. 오류 입력은 `aria-invalid` + `aria-describedby`, 오류 문구는 `role=alert`.
- **제목 순서**: h1(화면당 하나) → h2 → h3. 언어를 바꾸면 `<html lang>` 도 바뀐다.
- 외부 글자(소개글)는 `textContent` 로만 넣는다. `innerHTML`·`insertAdjacentHTML` 등은 `public/app` 에서 금지(시험이 확인).

## 브랜드(색)를 바꾸는 법

1. `tokens.css` 맨 위 **[바꿀 곳 A]** blue 한 줄의 hex 5개(900·700·500·100·50)를 새 브랜드 색 계열로 바꾼다. 주색·꼬리말 면·초점색이 따라간다.
2. 글꼴을 바꾸려면 **[바꿀 곳 B]** `--ui-font`(번들 글꼴을 쓰면 해당 `@font-face` 를 `design/fonts/` 에 둔다).
3. 사이트 전체를 다른 테마색으로 시작하려면 `<html data-accent="coral">` 처럼 붙인다.
4. `node --test tests/front-static.test.mjs` — 글자·단추 조합 대비(4.5:1)가 깨지면 어느 색인지 알려 준다.
5. 이름·메뉴·꼬리말·시간대는 `public/app/site.js`, 화면 문구는 `public/app/messages.js`(한·일·영 세 칸을 같이).
6. `public/samples/poster-*.svg` 는 견본이다. 실제 항목 이미지로 바꾼다(세로 3:4, 600×800 권장). 이미지가 없는 항목은 테마색 면 + 제목으로 그려진다.

## 대표 카드·분기

- 목록: 4건 이상이면 첫 항목이 대표 카드(가로형), 1~2건이면 전부, 3건이면 모두 같은 크기. JS 가 `.ui-card--featured` 를 붙인다.
- 분기: 1000px 이하 2열 · 760px 이하 1열 가로형 카드, 상세는 한 열 + 아래 고정 정보 바(`--ui-bar-reserve` 가 꼬리말에 자리를 비움, 가로로 눕힌 휴대폰은 고정 해제).
